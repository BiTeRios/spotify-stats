# Spotify Stats

Веб-приложение для просмотра персональной статистики Spotify.

## Технологии

### Frontend

- React
- TypeScript
- Vite

### Backend

- Python
- FastAPI

## Структура

- `frontend` — пользовательский интерфейс
- `backend` — REST API и интеграция со Spotify
